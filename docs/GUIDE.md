# CK2Commands 使用指南

> 《十字军之王 II》存档辅助工具。自动解析存档、写入图数据库，并生成可直接在游戏控制台执行的脚本命令。

---

## 快速开始

### 环境要求

运行前需确保以下服务已启动：

```bash
# 1. 启动 Nebula 图数据库（用于数据存储和分析）
cd /Users/thalesfu/codes/github.com/vesoft-inc/nebula-docker-compose
docker compose up -d

# 2. Neo4j 实例（ck2）已通过 Neo4j Desktop 启动
```

### 编译程序

```bash
cd /Users/thalesfu/codes/thalesproject/games/CK2Commands
go build -o ck2 ./main/main.go
```

## 命令行参数

```
./ck2 [参数...]
```

| 参数 | 说明 |
|------|------|
| *(无参数)* | 读取最新存档，写入数据库，生成 `auto.txt`（自动建议）和 `cure.txt`（治愈脚本） |
| `-w` | **监视模式**：持续监听存档目录，存档变化时自动重新处理 |
| `-f` | **强制重载**：不检查存档是否变化，直接重新解析写入 |
| `-bs` | **构建静态数据**：从游戏文件初始化文化、宗教、特性等参考数据 |
| `-target=neo4j` | 数据写入 Neo4j（**默认**） |
| `-target=nebula` | 数据写入 Nebula |
| `-target=both` | 同时写入两个数据库 |
| `-m` | **婚配模式**：为核心家族生成婚配建议脚本 |
| `-wr` | **宗教清洗**：生成批量改宗（道教）脚本 |
| `-c` | **文化同化**：为指定人物生成改变文化脚本 |
| `-r` | **宗教修改**：为指定人物生成改变宗教脚本 |
| `-t` | **头衔分配**：生成头衔分配脚本 |
| `-n` | **改名模式**：生成角色改名脚本 |

## 功能说明

### 一、默认模式（日常使用）

```bash
./ck2
# 或指定目标数据库
./ck2 -target=neo4j
```

**工作流程：**
1. 自动扫描两个存档目录，选取最新的 `.ck2` 文件
2. 若存档与数据库中记录的一致（相同文件路径 + SHA256 + 修改时间），跳过解析，直接生成脚本
3. 若存档已更新，重新解析并写入图数据库（耗时约 3 分钟）
4. 生成两个控制台脚本文件到游戏目录：
   - `auto.txt`：自动建议脚本（友谊建立、婚配安排、属性优化等）
   - `cure.txt`：治愈脚本（清除核心家族成员的疾病特性）

**脚本内容说明（auto.txt）：**

| 内容类型 | 说明 |
|---------|------|
| 建立友谊 | 玩家与核心家族成员互相建立友谊关系 |
| 婚配安排 | 为核心家族未婚成员匹配合适配偶（同文化、同宗教优先） |
| 生育/健康 | 提升配偶的生育力和健康值 |
| 治愈疾病 | 清除核心成员身上的疾病特性（胸痛、危险妊娠等） |

> 生成的 `.txt` 文件路径为 `{ck2安装目录}/auto.txt`，在游戏控制台中执行：
> ```
> run auto.txt
> run cure.txt
> ```

---

### 二、监视模式（游戏中实时使用）

```bash
./ck2 -w
# 输入 exit 退出
```

程序在后台持续监听存档目录（本地存档 + Steam 云同步目录）。每当游戏保存存档（无论自动存档还是手动存档），程序自动：
1. 检测到新 `.ck2` 文件
2. 重新解析写入数据库
3. 更新 `auto.txt` 和 `cure.txt`

适合游戏运行期间挂在后台，每次存档后立即得到最新脚本。

---

### 三、初始化静态数据（首次运行或游戏更新后）

```bash
./ck2 -bs -target=neo4j        # 写入 Neo4j（推荐）
./ck2 -bs -target=nebula       # 写入 Nebula
./ck2 -bs -target=both         # 两边同时写入
```

从 CK2 游戏安装目录解析并写入以下静态参考数据：

| 数据类型 | 来源文件 | 数量（参考） |
|---------|---------|------------|
| 文化 + 文化组 | `common/cultures/` | 129 种文化 / 34 组 |
| 宗教 + 宗教组 | `common/religions/` | 52 种宗教 / 7 组 |
| 特性 | `common/traits/` | 444 个特性 |
| 修正 | `common/event_modifiers/` + `common/trade_routes/` | 1519 个修正 |
| 建筑 | `common/buildings/` | 465 种建筑 |
| 野心/专注 | `common/objectives/` | 90 个目标 |

**仅需在以下情况重新运行：**
- 首次使用本工具
- 更新了游戏 Mod 或游戏版本

---

### 四、强制重载存档

```bash
./ck2 -f
./ck2 -f -target=neo4j
```

忽略存档的变化检测，强制重新解析当前最新存档并写入数据库。适用于：
- 数据库数据出现异常，需要重置
- 切换了 `-target` 目标，需要同步数据

---

### 五、婚配脚本生成

```bash
./ck2 -m
```

为核心家族（傅、楼、袁、褚、武、张、林、毕、殷、李）中所有未婚成员查询最合适的配偶候选，生成婚配命令脚本。匹配优先级：
1. 核心家族内部成员
2. 同宗教、同文化的藩属家族成员
3. 属性评分最优

---

### 六、其他脚本生成模式

| 命令 | 输出文件 | 说明 |
|------|---------|------|
| `./ck2 -wr` | `religion.txt` | 对核心家族及藩属批量生成改信道教脚本 |
| `./ck2 -c` | `culture.txt` | 对硬编码的指定人物生成改变文化脚本 |
| `./ck2 -r` | `religion.txt` | 对硬编码的指定人物生成改变宗教脚本 |
| `./ck2 -t` | `title.txt` | 生成头衔分配脚本（按 earth/ 目录下的头衔定义） |
| `./ck2 -n` | `name.txt` | 生成角色改名脚本 |

## 典型工作流

### 日常游戏

```bash
# 游戏启动前，后台挂起监视模式
./ck2 -w &

# 游戏内存档后（1~3 分钟解析完成），控制台执行：
# run auto.txt
# run cure.txt
```

### 新存档/切档

```bash
# 强制重新加载新存档
./ck2 -f

# 如果需要同时同步到 Neo4j
./ck2 -f -target=neo4j
```

### 首次配置

```bash
# 1. 启动数据库
docker compose up -d    # Nebula

# 2. 构建静态数据（只需一次）
./ck2 -bs -target=both

# 3. 加载当前存档
./ck2 -f -target=both
```
